# chore(deps): move the monorepo to TypeScript 6.0

## Change

- `typescript` goes from `^5.9.3` to `^6.0.3` in the 12 workspace manifests that declare it.
- Config fixes that TypeScript 6 needs:
  - `libs/messages/tsconfig.json` and `contrib/tools/e2e-report/tsconfig.json`: `"types": ["node"]`. TS 6 no longer includes `@types/node` implicitly.
  - `play/tsconfig.json`: `"rootDir": ".."`. `vite.config.ts` imports `../libs/messages`, and TS 6 defaults rootDir to the tsconfig directory.
  - `play/tsconfig-pusher.json`: remove `preserveValueImports` (removed in TS 6) and set `"rootDir": "."`.
- The lock must be regenerated with `npm install`.
