# chore(deps): update Svelte from 5.55.9 to 5.57.3

DRAFT. Not ready to open: the browser lifecycle lanes and the perf probe are still pending (see "Not verified yet").

## What changes

- `play`, `libs/store-utils` and `map-storage` declare `svelte` `^5.57.3` instead of `^5.55.9` (one line each).
- The root `package-lock.json` resolves a single `svelte@5.57.3`.
- Svelte 5.57.3 raises the minimum of some of its own dependencies, so the lockfile also moves `acorn` 8.16.0 to 8.19.0, `esrap` 2.2.9 to 2.4.0, `devalue` 5.8.1 to 5.9.4, `@sveltejs/acorn-typescript` 1.0.10 to 1.0.13 and `@jridgewell/sourcemap-codec` 1.5.5 to 1.6.0. `@types/trusted-types` stays at 2.0.7 and becomes `optional`. `acorn` and `@jridgewell/sourcemap-codec` are hoisted and shared with other build tooling.
- No source file, configuration or other dependency changes. `desktop/electron` already declares `^5.57.3` in its own lockfile and is untouched.

## Why

5.57.3 is the current `latest` (published 2026-10-26). The 15 releases since 5.55.9 contain upstream fixes for objects kept alive after teardown, in code paths this front end uses heavily (runes, delegated event attributes, `<svelte:window>`/`<svelte:document>`):

- prevent untracked derived reads from retaining disconnected dependencies ([#18829](https://github.com/sveltejs/svelte/pull/18829))
- prevent duplicate subscriptions when reconnecting deriveds ([#18899](https://github.com/sveltejs/svelte/pull/18899))
- cancel deferred event listeners during cleanup ([#18749](https://github.com/sveltejs/svelte/pull/18749))
- keep the dependencies of a reaction that throws, so deriveds it read are not leaked ([#18703](https://github.com/sveltejs/svelte/pull/18703))
- release `last_propagated_event` after propagation settles so it no longer retains the last event's target subtree ([#18569](https://github.com/sveltejs/svelte/pull/18569))
- clean up removed capture event handlers from spread attributes ([#18618](https://github.com/sveltejs/svelte/pull/18618))
- abort a derived's own AbortSignal when it disconnects ([#18400](https://github.com/sveltejs/svelte/pull/18400))
- remove `<svelte:head>` anchors on unmount ([#18697](https://github.com/sveltejs/svelte/pull/18697))

Full changelog: <https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md>

This is a maintenance upgrade. It does not claim a memory or speed improvement for WorkAdventure: that has not been measured.

## Risk review

Releases in this range add compile errors and diagnostics that could have failed `svelte-check --fail-on-warnings` ([#18900](https://github.com/sveltejs/svelte/pull/18900), [#18842](https://github.com/sveltejs/svelte/pull/18842), [#18873](https://github.com/sveltejs/svelte/pull/18873), [#18480](https://github.com/sveltejs/svelte/pull/18480), [#19045](https://github.com/sveltejs/svelte/pull/19045)). None fired: `svelte-check` reports 0 errors and 0 warnings before and after. `flushSync` now flushes pending work before its callback ([#18878](https://github.com/sveltejs/svelte/pull/18878)); the component tests that mount Svelte components pass unchanged.
