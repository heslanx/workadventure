# chore(ts): pilot the native TypeScript 7 compiler for back and map-storage typechecks

Depends on the TypeScript 6 change (D01a).

## Change

- Root, back and map-storage add `"@typescript/native": "npm:typescript@^7.0.2"`. The `tsc` bin is the native compiler.
- `typescript` becomes `npm:@typescript/typescript6@^6.0.2` in every workspace that declared it. `require('typescript')`, `tsc6` and `tsserver` stay on TypeScript 6.0.3 for typescript-eslint, svelte-check, ts-loader and editors.
- Existing scripts move from `tsc` to `tsc6`, so their behaviour does not change.
- New `typecheck:native` scripts in back and map-storage.

## Verified (remote copy of `ddbe245a8`, node 24, `--cpus 2`)

- Resolution:
  - From root, back and map-storage: `tsc -v` gives 7.0.2, `tsc6 -v` gives 6.0.3, and `require('typescript').version` is 6.0.3.
  - The same links come out of a full `npm ci` and of scoped `npm ci --workspace=...` (exit 0).
- Diagnostics:
  - Clean tree: both compilers exit 0 with no output.
  - With an injected type error: both report the same TS2322 line.
  - Exit codes differ on errors: native exits 1, TS 6 exits 2.
- TypeScript 6 API consumers: play svelte-check, store-utils svelte-check, all `tsc6` typecheck scripts, and typed eslint on 7 files all exit 0.

Typecheck time, 5 interleaved runs each, medians:

| | TS 6.0.3 wall / user CPU / peak RSS | native 7.0.2 wall / user CPU / peak RSS |
|---|---|---|
| back `--noEmit` | 9.57 s / 14.22 s / 879 MiB | 3.83 s / 6.08 s / 768 MiB |
| map-storage `--noEmit` | 6.72 s / 9.75 s / 626 MiB | 2.29 s / 3.21 s / 442 MiB |

These are CI/dev typecheck times on a capped shared VPS. They are not runtime or capacity numbers.
