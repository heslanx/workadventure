# Microcopy

Audit of user-visible text in `play/src/front` (490 `.svelte` files) and the catalogues in `play/src/i18n/en-US` and `play/src/i18n/pt-BR`. Audit only, no source edited. Line numbers are from the working tree on branch `chore/orca-docker-ssh-env`. en-US lines are cited first, pt-BR lines in parentheses when they differ.

Reading notes:

- Many catalogue keys are dead (no caller in `play/src/front`). Findings below cite only keys with a live caller, except where marked "unused".
- pt-BR is a `DeepPartial`, so any key it omits falls back to English at runtime. That is why English text shows up inside the pt-BR files (see Needs a product decision, item 5).
- Proposals use only periods, commas and parentheses. No colon, exclamation mark, emoji or dash.

## Forbidden punctuation

Ranked by how often a real user meets the string.

1. `play/src/i18n/en-US/notification.ts:12` (pt-BR `notification.ts:12`). Caller: `Space/Utils/BindMuteEvents.ts:178`, shown when a moderator gives you the floor.
   - Current en: `It's your turn to speak — enable your microphone`
   - Current pt: `É a sua vez de falar — ative o microfone`
   - Rule: em dash. Also "enable" breaks the on/off verb (see Vocabulary drift).
   - en: `It's your turn to speak. Turn on your microphone.`
   - pt: `É a sua vez de falar. Ligue o microfone.`
   - Confidence: high.
2. `Notification/MessageNotification.ts:37`. Desktop-app notification title.
   - Current: `` `${this.chatRoomName} — ${body}` ``
   - Rule: em dash, and it is built in code, so no translator can fix it.
   - Proposed: `` `${this.chatRoomName}. ${body}` `` (same string for en and pt).
   - Confidence: high.
3. `en-US/desktop.ts:156` and `:157` (pt-BR already fixed at `desktop.ts:157,158`). Shared component: the annotation device picker in `Components/Video/PictureInPicture` (keys `cameraOff`, `microphoneOff`).

   - pt (already compliant in spirit, colon should become a period): `Sua câmera está desligada. Ligue-a para escolher uma.` and `Seu microfone está desligado. Ligue-o para escolher um.`
   - Confidence: high.
4. `en-US/externalModule.ts:27` and `pt-BR/externalModule.ts:27`. Shown in the Teams meeting popup when the account cannot create meetings.
   - Current (both locales, pt is untranslated): `Wait for a participant who can create it, or reconnect — if your administrator has just enabled it, reconnecting is enough.`

## Needs a product decision

1. Glossary owner and the room / map / world / space split. Four rows of Vocabulary drift depend on it. Recommendation in the table, but "room" is also the WorkAdventure URL-level term (`Room Settings`, `Configure my room`), so renaming it to "map" touches the map editor, the docs and the admin. Decide once, then fix both locales together.
2. Error screen policy. Do we hide the error code (`ErrorScreen.svelte:90-92`) or keep it behind a "Show details" toggle for support? And should `type "error"` get a "Reload page" button (`ErrorScreen.svelte:100`) or stay a dead end? Proposals above assume the code moves to console and Sentry.
3. `Woka` versus `avatar`. `Woka` is the product's own term, used in about 10 pt-BR and 10 en-US strings, while onboarding and actionbar already say `avatar`. Pick one.
4. How strict the punctuation rule is. Read literally ("only periods, commas or parentheses"), 46 exclamation marks, 61 emoji, the colons in pt-BR `desktop.ts:157-158`, 3 middle dots and every `(…)` ellipsis are violations. This audit treated em and en dashes as the hard rule and proposed colon-free text for the strings it touched. Also decide how to write time ranges (`10:00 to 11:00` needs a new key, Calendar files).
5. pt-BR coverage and translation fallback. `pt-BR/externalModule.ts:23,24,25,27,29,89,101,102` are English. Decide whether to translate them in this pass, and whether CI should fail on a missing pt-BR key. In the same pass, resolve the `Entrar` (login and join) and `Sair` (log out and leave) overlap from the Vocabulary drift table.
6. Technical terms in the chat settings: `Matrix user ID`, `Homeserver` (`chat.ts:818,819`), `Shown only when DEBUG_MODE is on` (`chat.ts:845`), `SSO` (`chat.ts:631`), `TURN` (`camera.ts:75`), `Klaxoon` / `Eraser` / `Tldraw` tool names. Show to everyone, to admins only, or rename.
7. Whether `Cancel` (21) and `Close` (14) count as bare confirm labels. The rule names OK, Sim and Confirmar. This audit flags only the confirm-class labels and leaves `Cancel` as an acceptable dismiss. Confirm before anyone sweeps them.
8. Minor names, one decision each: `Place` / `Lugar` versus `area` (`megaphone.ts:9-11,22`), `Silent zone` / `Zona silenciosa` versus `area` (`camera.ts:89`), `thread` versus pt `tópico` (pt-BR `chat.ts:246,256,585`), `Business card` versus `Visit card` (`chat.ts:25,49`, `woka.ts:19`, `desktop.ts:111`), and `Locate` (`follow.ts:25`, `chat.ts:52`) versus the shortcut `Follow` (`menu.ts:164`) and `Ask to follow` (`actionbar.ts:123`).

## Decisions (session 2)

1. Glossary (room / map / world / space). No global rename in this pass. "Room" stays the WorkAdventure term for URL-level places (`Room Settings`, `Configure my room`) and for Matrix chat rooms, because it is the word the product already uses most. New or rewritten text uses `world` for the whole set of maps, `map` for the place you walk in when the surrounding text already says map (Explorer, LimitRoomModal), and `area` for zones. `space` is not used in any new string. A full glossary sweep stays with the glossary owner.
2. Error-screen policy. Errors raised in the browser (`ErrorScreenStore.setException`) now show a translated title and next step, chosen in `ErrorScreen.svelte` from a new `clientErrorKind` field so the text follows the loaded locale. The error code and the technical text (HTTP status, URL, exception message) move behind a native `<details>` "Show details" toggle: hidden by default, keyboard operable, still selectable for support, and still in the DOM for e2e assertions. Every `type: "error"` screen now has a "Reload the page" button instead of a dead end. Server-sent errors keep their server title and details.
3. Login and join verbs. en `Log in` / `Log out` everywhere (`Login`, `Sign in`, `Logout` replaced). pt keeps `Entrar` / `Sair`, which is what the pt catalogue already says for log in and log out; join keeps `Entrar` / `Participar` as it already is. The pt overlap is left as a known limit, not resolved by renaming.
4. Jargon. `TURN server` and `video relay server` become plain words (`video server`, `Video connection problem`). `Matrix user ID`, `Homeserver`, `SSO`, `DEBUG_MODE` and tool brand names are out of the 40 ranked rows and stay as they are.
5. `Woka` versus `avatar`. Keep the brand term where the screen already uses it: the WOKA picker button says `Use this WOKA` (pt `Usar este personagem`, matching the pt screen title). No sweep of other strings.
6. Devices. en `Turn on` / `Turn off`, `camera` (not `webcam`, not `cam`), pt `Ligar` / `Desligar`, `câmera`. `mute` / `silenciar` kept for audio only; the camera mute request button says `Turn off my camera`.
7. Sentry feedback `confirmButtonLabel` is the screenshot editor's confirm button (checked in `@sentry/core` types), so it becomes `Save screenshot`, not `Send report`.
8. Threads in pt stay `thread` (the panel already says threads); `tópico` is not introduced.
